# COVID-19 Data Analysis and Visualization

## Project Overview

This project performs exploratory data analysis and visualization of
COVID-19 data using Python, SQL Server, Pandas and Plotly.

The project analyzes COVID-19 cases, deaths, recoveries and testing
data across different countries and over time.

## Technologies Used

- Python
- SQL Server
- Pandas
- PyODBC
- Plotly
- VS Code
- Git & GitHub

## Project Features

- SQL Server database connection
- COVID-19 data loading
- Exploratory Data Analysis
- Data visualization
- Time-series analysis
- Country-wise COVID-19 analysis
- Global COVID-19 map
- COVID-19 analysis insights
- Interactive dashboard

## Analysis Performed

The project analyzes:

- Total COVID-19 cases
- Total deaths
- Total recovered cases
- Total tests
- Daily new cases
- Country-wise comparison
- Global trends
- Cases vs deaths relationship
- Recovery rate
- Case fatality rate

## Dashboard

The project includes an interactive Plotly dashboard
containing KPI cards, charts and COVID-19 trends.

## Database

The project uses Microsoft SQL Server as the database
and Python PyODBC for database connectivity.
